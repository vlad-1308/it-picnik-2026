# Как обновлять расписание ИТ-Пикника

## Главное правило

После публикации полной программы редактируется только `schedule-data.js`.

Интерфейс программы, фильтры, конфликты, блок «Сейчас», персональный маршрут и переходы на карту реализованы в `schedule-engine.js` и не требуют изменений.

## Что сделать после появления официального PDF / таблицы

1. Поставить `status: "full"`.
2. Обновить `dataVersion` и `source.publishedAt`.
3. Перенести каждый слот в `events`.
4. Для докладов поставить `trackId` и `locationId`.
5. Оценить полезность через `score.vlad` / `score.yulia` от 0 до 3.
6. После выбора маршрута указать `plan`:
   - `["both"]` — идём вместе;
   - `["vlad"]` — только Влад;
   - `["yulia"]` — только Юля;
   - `[]` — не входит в финальный маршрут.
7. Commit в `main`. GitHub Pages подхватит данные автоматически.

## Минимальный объект события

```js
{
  id: "eng-1340-sdlc",
  start: "13:40",
  end: "14:20",
  title: "Название доклада",
  type: "talk",
  trackId: "engineering",
  locationId: "eng3",
  speaker: "Имя Фамилия",
  company: "Т-Банк",
  description: "Коротко о содержании",
  score: { vlad: 3, yulia: 1 },
  reasons: {
    vlad: "Почему полезно Владу",
    yulia: "Почему полезно Юле"
  },
  plan: ["vlad"],
  official: true
}
```

## Стабильные trackId

- `products` → Лекторий 1 / Продукты от и до
- `data` → Лекторий 2 / От данных к решениям
- `engineering` → Лекторий 3 / Инженерная продуктивность
- `cyber` → Лекторий 4 / Кибербезопасность
- `bigtech` → Лекторий 5 / Бигтех в каске
- `genai` → Лекторий 6 / Генеративный ИИ
- `education` → Образование
- `science` → Научпоп
- `music` → Музыкальная сцена

## Стабильные locationId

`prod1`, `data2`, `eng3`, `cyber4`, `big5`, `gen6`, `education`, `science`, `mainstage`, `flat`, `team`, `tech`, `auto`, `tproducts`.

`locationId` автоматически связывает карточку программы с интерактивной картой. Кнопка «🗺 Карта» сама переключит вкладку и приблизит нужную точку.

## Проверка после обновления

В консоли браузера:

```js
ITP_SCHEDULE_API.validate()
```

Ожидаемый результат: `[]`.

Дополнительно:

```js
ITP_SCHEDULE_API.planned('vlad')
ITP_SCHEDULE_API.planned('yulia')
```

показывают итоговые персональные маршруты.
